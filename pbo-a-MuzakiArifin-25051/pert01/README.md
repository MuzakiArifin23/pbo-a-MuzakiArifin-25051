## Ringkasan langkah

1. Instal Git di komputer lokal.
2. Atur konfigurasi Git:
   ```bash
   git config --global user.name "Nama Lengkap Anda"
   git config --global user.email "email-yang-sama-dengan-github@contoh.com"
   git config --global init.defaultBranch main
   ```
3. Buat kunci SSH (ikuti panduan GitHub), lalu tambahkan ke akun GitHub.
4. Uji koneksi: `ssh -T git@github.com`
5. Hubungkan repositori lokal ke GitHub, lalu `git add`, `git commit`, `git push`.
